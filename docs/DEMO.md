# 시연 대본 (4분 — 동작·사용법 위주, 회원가입 포함)

> 발표: 박효민. **화면이 말하게 한다** — 대사는 클릭을 따라가는 한 줄씩만.

## 사전 세팅 (시연 10분 전)

- [ ] `cd server && uv run uvicorn main:app --port 8000` — 서버 기동
- [ ] 워밍업: 아무 시나리오 1회 생성 (첫 클릭 지연 제거)
- [ ] **창 배치**: 브라우저 왼쪽 ⅔ · 서버 터미널 오른쪽 ⅓ (인증번호가 여기 뜬다)
- [ ] **브라우저 줌 125%** (프로젝터에서 작아 보임 방지)
- [ ] 랜딩(`localhost:8000`)에 대기 · 백업 = README GIF

## 타임라인

### 0:00–0:15 | 랜딩
- **[내 로드맵 그리기 →]** 클릭
- 💬 "직무를 고르면 졸업까지의 길이 그려지는 서비스입니다. 회원 흐름부터 보여드리겠습니다."

### 0:15–1:05 | ★ 회원가입 — 이메일 인증번호 (터미널과 함께)
- 네비 **[로그인]** → 회원가입 전환
- 아이디 입력 → **[중복 확인]** ("✓ 사용 가능") → 이름·학과·비밀번호
- 이메일 입력 → **[인증번호 받기]** → **오른쪽 터미널을 가리키며**:
  💬 "지금은 메일 서버 없이 도는 데모 모드라 번호가 콘솔로 옵니다 — **메일이 막혀도
  시연이 죽지 않게 설계한 이중화**고, SMTP만 붙이면 실제 메일로 갑니다."
- 번호 입력 → 완료 배지 → **약관 전체 동의** (버튼 잠금 풀리는 것 보여주기) → **[가입]**
- 💬 "가입 즉시 로그인됩니다." (네비가 '내 정보'로 바뀜)

### 1:05–1:50 | 로드맵 생성 — 직무 미정 추천
- 학과 **정보통신공학과** · 1학년 1학기 · 직무 **"아직 못 정했어요 — 추천받기"** → **[로드맵 생성]**
- 💬 "직무를 못 정한 학생이면, 학과 교육과정에서 배정 학점이 가장 많은 직무를 근거와
  함께 추천합니다. 응답은 즉시 — 매번 같은 결과가 재현됩니다."
- 추천 배너 → 후보 칩 **시스템관리·운용엔지니어** 클릭 → 재생성
- 하단 배지 읽기: 💬 "전공 78/66 · 교양필수 3/3 · 재학 6학기 — 이 로드맵은 그럴듯한 게
  아니라 **검증된** 겁니다. 남은 29학점도 숨기지 않고 알립니다."

### 1:50–2:30 | 트랙 조작
- **학기 노드(2-1) 클릭** → 캐릭터 걷기 → 패널: ★직무 과목 + "운영체제·네트워크Ⅰ 이수 후
  네트워크관리사 준비" 조언
- **자격증 분기 클릭** → 자격증 패널 (Q-Net 연결)
- 💬 "무엇을 언제 듣고, 자격증은 언제 준비할지가 학기 단위로 박힙니다."

### 2:30–2:55 | 저장 (가입과 수미상관)
- **[로드맵 저장]** → 네비 [내 정보] → 저장된 로드맵 확인
- 💬 "회원이면 이렇게 저장해 두고, 학교 SMART CARE에 등록할 재료로 씁니다."

### 2:55–3:45 | 학교용 리포트 (트랙 B)
- 네비 **[학교용 리포트]** → 정보통신공학과
- 💬 "같은 데이터를 학교 쪽에서 보면 — 학과가 홍보하는 진로 6개 중 5개는 교육과정에
  대응 과목이 없습니다. 숨기지 않고 '교육과정 미대응'으로 표시합니다."
- 자격증 대응 절 한 컷 → 학과를 **드론정보공학과**로
- 💬 "이 학과는 전공을 전부 이수해도 43학점 — 요건 45에 2학점 부족합니다. 2026학년도
  원본 교육과정표로 확정한, **저희 시스템이 찾아낸 실제 결손**입니다."

### 3:45–4:00 | 마무리
- 로드맵 화면에서 **F5** (멀쩡함)
- 💬 "교육과정표 한 장을 들고 있던 학생에게, 3분 전엔 없던 답이 생겼습니다. 감사합니다."

## 컷 우선순위 (시간 밀리면)

저장(2:30 구간) → 트랙 조작 축소. **가입·미정 추천·검증 배지·드론은 컷 금지.**

## 질의응답 예상 (한 줄 답)

| 질문 | 답 |
|---|---|
| AI는 어디에? | 개발 전 과정 Claude Code 페어 프로그래밍(보고서 §2) + LLM 에이전트를 만들어 규칙 엔진과 비교 검증, 옵트인 모드로 탑재 |
| 왜 LLM이 메인이 아닌가 | 둘 다 만들어 실측 비교 — 근거 투명성·0.1초 응답·재현성으로 규칙 선택. `engine` 필드로 항상 무엇이 돌았는지 밝힘 |
| 15%→99.3%는? | 274개 시나리오 전수. 1차 생성만으론 15%, 검증-재생성 루프 후 99.3%. `uv run python metrics.py`로 이 자리에서 재현 가능 |
| 드론 43학점, 예외 규정 있다면? | 있다면 그것대로 "공개 요건과 편성의 불일치"라는 발견 — 어느 쪽이든 진단 대상 |
| SMART CARE와 차이 | 그쪽은 등록하는 곳, 우리는 만들어주는 엔진 — 우리 출력물이 그쪽 입력물 (상류 공정) |
| 미달 로드맵은? | 3회 재생성 후에도 미달이면 부분 로드맵 + 미달 사유를 그대로 보여줌 — 실패를 숨기지 않음 |
