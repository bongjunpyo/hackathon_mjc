# 프론트 v2 화면 설계서

> 2026-08-07 새벽 확정. 3D 복도 컨셉을 폐기하고 **2D 트랙(기찻길) 컨셉**으로 전환한다.
> 근거 문서: [API 명세서](API.md) · [구현 계획서](PLAN.md). 서버·데이터는 변경하지 않는다.

## 0. 방향 선언

- **2D로 간다.** 3D 원근(perspective) 코드는 전부 삭제한다. 걷는 캐릭터(Walker SVG)는 2D 자산이므로 **재사용**한다 — 랜딩에서 걷던 사람이 로드맵 트랙 위를 걷는다.
- **메인 화면 = 로드맵.** 입력 전용 페이지(`Input.jsx`)를 폐지하고 메인 상단 컨트롤 바로 흡수한다.
- **화력은 메인에 집중한다.** 심사위원이 가장 오래 볼 화면이고, 잘리면 안 되는 유일한 화면이다.
- 라이브러리 추가 금지 유지. 트랙은 SVG, 이동은 CSS `offset-path`로 만든다.

## 1. 정보 구조 · 라우팅

```
/            랜딩 (2D)
/roadmap     ★ 메인 — 로드맵 스튜디오 (컨트롤 바 + 트랙 캔버스)
/explore     학과 탐색 — 34개 카드 그리드
/explore/:deptId   학과 상세 — 커리큘럼 표 · 자격증 · 진로 · [내 로드맵 그리기]
/report      학교용 리포트 (트랙 B, 기존 유지)
/login       로그인/회원가입 (옆문 — 어떤 흐름도 이 페이지를 강제 통과하지 않는다)
```

**상단 네비 (전 페이지 공통, 랜딩 제외)**: `로고 | 로드맵 | 학과 탐색 | 학교용 리포트 | ─ | 로그인`
게스트가 기본이다. 로그인은 저장 기능을 쓸 사람만 여는 옆문이며, 미로그인 상태에서 잠기는 화면은 없다.

**사용자 여정 2개**가 이 구조의 근거다 (설계서 §1 "정보격차는 신입생·편입생에게 더 크다"):

```
재학생   : 랜딩 → /roadmap → 생성 → 탐색(캐릭터) → [저장(로그인 시)]
예비입학생: 랜딩 → /explore → 학과 상세 → [내 로드맵 그리기] → /roadmap (학과 미리 선택됨)
```

## 2. 메인 — 로드맵 스튜디오 (`/roadmap`)

### 2.1 레이아웃

```
┌──────────────────────────────────────────────────────────────┐
│ 네비                                                          │
├──────────────────────────────────────────────────────────────┤
│ 학과 ▾ │ 학년/학기 ▾ │ 목표 직무 ▾ │ [이수과목 ▾] │ (로드맵 생성) │ ← 컨트롤 바
├──────────────────────────────────────────┬───────────────────┤
│                                          │  학기 상세 패널     │
│           트랙 캔버스 (SVG)               │  (노드 선택 시)     │
│                                          │                   │
├──────────────────────────────────────────┴───────────────────┤
│ 전공 78/66 ✓ · 교양필수 3/3 ✓ · 학기 6/6 ✓ · 남은 29학점 │ AI생성 │ ← 검증 배지 바
└──────────────────────────────────────────────────────────────┘
```

- 데스크톱: 패널은 우측 340px 고정, 캔버스가 나머지. 모바일(<768px): 패널이 하단 시트로.
- 검증 배지 바는 `validation`이 있을 때만 렌더. `engine` 값을 우측 끝에 작은 태그로 표시 — `llm`이면 "AI 생성", `rule`이면 "규칙 생성(폴백)". **폴백을 숨기지 않는다.**

### 2.2 컨트롤 바

| 컨트롤 | 소스 | 동작 |
|---|---|---|
| 학과 | `GET /depts` (폴백: `lib/depts.js`) | 선택 시 직무·이수과목 컨트롤 리셋 |
| 학년/학기 | `years`에서 파생 (2년제 1-1~2-2, 3년제 ~3-2) | 선택 시 이수과목 드로어에 **이전 학기 전 과목 자동 체크** (`lib/curricula.js coursesBefore` 재사용) |
| 목표 직무 | **`talent_types` 우선** + `careers` 이어붙임 | talent_types가 과목 라벨과 직결 — 드롭다운 기본 노출 순서 |
| 이수과목 | 드로어(접힘 기본). 자동 체크 후 개별 토글 | `course_id` 배열로만 관리 |
| 생성 버튼 | — | 학과+직무 선택 전 disabled. 클릭 → `POST /roadmap` |

### 2.3 트랙 캔버스 — 지오메트리

노드 목록: `[입학, ...학기(4|6), ★직무]` — 3년제 8개, 2년제 6개.

- **서펜타인 배치**: 행당 3역, 행 방향 교대(→ ← →). `viewBox="0 0 1200 H"`, 행 높이 190.
  좌표: `row = floor(i/3)`, `col = i%3` (홀수 행은 `2-col`로 반전), `x = 150 + col*450`, `y = 120 + row*190`.
- **본선 path**: 노드 좌표를 잇는 폴리라인. 꺾이는 지점은 `Q`(quadratic)로 반경 40 라운딩 — 캐릭터가 모서리에서 순간 꺾이지 않게.
- **분기 노드(자격증·이력서·포트폴리오)**: 해당 학기 노드에서 45° 아래로 길이 90 가지. 행이 반전이면 위로. 한 학기에 분기 2개까지 부채꼴, 3개 이상은 패널에서만.
- 노드 스타일: 이수 완료(체크·어두움) / 현재(캐릭터 위치, 강조 링) / 미래(기본) / ★종착(직무명 라벨 + 배지 자리).

### 2.4 캐릭터 (커서 모델)

**캐릭터 위치 = "보고 있는 학기". 이동은 API를 다시 부르지 않는다.** 재생성은 오직 [로드맵 생성] 버튼.

| 트리거 | 동작 |
|---|---|
| 첫 진입 | `입학` 역에 캐릭터 |
| 생성 완료 | 트랙 드로잉 애니메이션 → 캐릭터가 입학에서 **현재 학기(입력값)까지 걸어감**. 지나온 역은 이수 스타일 |
| 학기 노드 클릭 | 캐릭터가 그 역까지 트랙을 따라 걸어감 → 도착 시 해당 학기 패널 열림 |
| 패널 우측 하단 `[다음 학기 →]` | 다음 역으로 이동 + 패널 갱신. 마지막 학기에선 `[졸업 →]`로 바뀜 |
| `[졸업 →]` | ★직무 역까지 걸어감 → **"졸업요건 충족 ✓" 배지 팝** (passed=true일 때) |

구현: 본선과 동일한 path 문자열을 캐릭터의 `offset-path`로 지정, 역별 `offset-distance` %는 노드 좌표의 누적 선분 길이로 계산(직선 구간이라 산술 계산으로 정확). 이동은 `transition: offset-distance 0.6s/역 × 거리`, 이동 중 Walker 다리 애니메이션 재생, 진행 방향이 왼쪽이면 `scaleX(-1)`. `prefers-reduced-motion`이면 트랜지션 없이 즉시 배치.

### 2.5 상태 5종

| 상태 | 화면 |
|---|---|
| INIT | 흐릿한 예시 트랙 + "학과와 직무를 고르면 여기에 당신의 길이 그려집니다" |
| GENERATING | 캐릭터 제자리걸음 + 단계 문구 순환("AI가 로드맵 생성 중… → 졸업요건 검증 중…"). **27초 침묵을 연출로 바꾼다** |
| READY | 트랙 드로잉 → 캐릭터 이동 → 탐색 가능 |
| PARTIAL | `passed=false` (3회 초과): 트랙은 그리되 미달 구간 붉게, `details[].fix` 문구 표시, 캐릭터는 미달 지점 앞에 멈춤 — **검증기가 잡아냈다는 증거 화면** |
| ERROR | `error.message` 그대로 표시 (400/404/네트워크) + 재시도 버튼 |

### 2.6 학기 상세 패널

```
2학년 1학기 · 15학점
├ 운영체제 (3) ★목표직무          ← talent_type == target_job이면 ★
├ 라우팅및스위칭 (3) ★ · 현장중심
├ …
🎯 자격증: CCNA — "운영체제·네트워크Ⅰ 이수 후 준비"   ← certificates + notes
                                    [다음 학기 →]
```

과목 행: 이름·학점·이수구분, ★목표직무 배지, 현장중심 태그. 이력서/포트폴리오 항목은 §3 규칙으로 프론트가 주입.

## 3. 이력서·포트폴리오 타이밍 (프론트 규칙 — 데이터 아님)

데이터에 없는 값을 지어내지 않는다. 아래 **일정 조언 규칙 2줄**만 프론트에서 계산해 분기 노드로 꽂는다:

1. `field_based`(현장실습) 과목이 처음 나오는 학기의 **직전 학기** → "이력서 준비" 분기
2. **마지막 학기** → "포트폴리오 완성" 분기

## 4. 학과 탐색 (`/explore`) · 학과 상세 (`/explore/:deptId`)

**데이터는 전부 프론트 번들에 이미 있다** (`lib/depts.js`, `lib/curricula.js`). 서버 추가 작업 0.

- **탐색**: 34개 카드 그리드. 카드 = 학과명 · 학제(2/3년제) 배지 · 대표 직무 2개 · 자격증 수. 컨트롤은 **이름 검색 + 학제 필터** 둘만 — 계열 분류 데이터가 없으므로 지어내지 않는다.
- **상세**: 학제·인재양성유형(`talent_types`)·취득 자격증·진로(`careers`) + **학기별 커리큘럼 표**(연-학기 그룹, 과목명·학점·이수구분·직무 라벨). 하단 고정 CTA **[이 학과로 내 로드맵 그리기]** → 컨텍스트에 학과를 넣고 `/roadmap` 이동. 탐색 페이지가 깔때기가 되게 하는 장치이며, 이 버튼 없이는 고립된 페이지다.

## 5. 랜딩 (`/`) — 2D 전환

- 3D 복도(perspective·translateZ·걸음-노면 동기화) 코드 삭제. `Corridor.jsx`에서 Walker·행선판·SVG 자산만 회수.
- 구성: 히어로(카피 + 걷는 Walker + 2D 트랙 일러스트) → 문제 한 줄("교육과정표 PDF 한 장") → 3스텝 소개(학과·직무 선택 → AI 생성 → 검증기 확인) → CTA 2개 **[내 로드맵 그리기]** `/roadmap` · **[학과 둘러보기]** `/explore`.
- 스크롤 연출은 선택 사항(컷 1순위). 정적이어도 성립해야 한다.

## 6. 디자인 토큰

기존 브랜드 토큰 유지: `navy #002D65`(주) · `sky #6DCBF9`(트랙·강조) · `gold #FFBA00`(배지·★). Tailwind 테마 등록값만 사용, 컴포넌트 헥사 하드코딩 금지. 노드 상태색: 이수 `navy/40%`, 현재 `gold`, 미래 `navy`, 미달 `red-500`.

## 7. 접근성

- `prefers-reduced-motion`: 캐릭터 이동·트랙 드로잉·제자리걸음 전부 생략, 상태는 즉시 반영.
- 트랙 노드는 `<button>`으로 — 키보드 탐색(Tab)과 Enter 이동 가능. 패널 `[다음 학기 →]`와 동일 동작.
- 캔버스와 별개로 패널이 텍스트 정보를 전부 담는다 — 트랙은 연출, 정보는 패널.
