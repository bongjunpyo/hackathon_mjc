# 프론트 v2 구현 계획서

> 마감 오늘 12:00 · 제출 11:40. 이 문서는 **역산 계획**이다 — 늦어지면 아래 컷 라인대로 자르고, 절대 미루지 않는다.
> 설계: [DESIGN.md](DESIGN.md) · 계약: [API.md](API.md)

## 0. 원칙

1. **main은 항상 데모 가능해야 한다.** v2는 `p3/front-v2` 브랜치에서 만들고, 데모 경로(생성→트랙→배지)가 v1 이상으로 동작할 때만 머지한다. 머지 전까지 main의 v1이 보험이다.
2. **서버·데이터 변경 0.** 계약은 API.md에 고정. 서버를 고치고 싶어지면 그 기능을 컷한다.
3. 단계마다 **검증을 통과해야 다음 단계**로 간다. 검증은 "눈으로 확인"까지 포함 — 빌드 통과는 증명이 아니다.
4. 커밋은 단계마다 1개 이상. `feat(웹): …` 형식.

## 1. 단계별 계획

### P0. 준비 (15분)

| 작업 | 내용 |
|---|---|
| 브랜치 | `p3/front-v2` 생성 |
| 골격 | 라우터에 `/roadmap` `/explore` `/explore/:deptId` 추가. 기존 페이지는 **삭제하지 않고** 새 라우트를 병행 — 스위치는 마지막에 |
| 자산 회수 | `Corridor.jsx`에서 `Walker` 컴포넌트를 `components/track/Walker.jsx`로 분리 (SVG 그대로) |

**검증**: `npm run build` 통과, 기존 화면 전부 그대로 동작.

### P1. 트랙 캔버스 코어 (2h) — 최우선

| 작업 | 내용 |
|---|---|
| `lib/track-geometry.js` | 노드 배열 → 서펜타인 좌표 · 본선 path 문자열 · 역별 누적거리 % (DESIGN §2.3 공식). **순수 함수로** — 테스트 없이도 콘솔에서 검증 가능하게 |
| `TrackCanvas.jsx` | SVG 렌더: 본선 path, 학기 노드(button), 분기 노드, ★종착. 상태별 스타일(이수/현재/미래/미달) |
| `SemesterPanel.jsx` | 과목 목록 · ★직무 배지 · 자격증+notes · `[다음 학기 →]` |
| `ValidationBar.jsx` | 배지 4종 + 남은 학점 + engine 태그 |

**목데이터로 만든다** — 실측 응답이 **`docs/frontend/fixtures/roadmap-demo.json`에 준비돼 있다** (P1이 실제 LLM으로 생성: 31초 · engine=llm · passed=true). `web/src/fixtures/`로 복사해 사용. API 연동은 P3.
**검증**: 목데이터로 3년제(8노드)·2년제(6노드) 트랙이 그려지고, 노드 클릭 시 패널이 바뀐다.

### P2. 캐릭터 인터랙션 (1.5h)

| 작업 | 내용 |
|---|---|
| Walker 이동 | `offset-path` + `offset-distance` 트랜지션, 역별 % 매핑, 이동 중 걷기 애니메이션·방향 반전 |
| 커서 상태 | `cursor` 인덱스 하나로 노드클릭·[다음 학기]·[졸업] 통합 (DESIGN §2.4 표) |
| 배지 팝 | ★ 도착 + `passed` → 배지 애니메이션 |
| reduced-motion | 트랜지션 제거, 즉시 배치 |

**검증**: 클릭·버튼으로 앞뒤 이동이 자연스럽고, 발이 트랙을 벗어나지 않는다. OS 모션 감소 설정에서 즉시 점프.

### P3. 컨트롤 바 + API 연동 (1.5h)

| 작업 | 내용 |
|---|---|
| 컨트롤 바 | 학과·학년/학기·직무·이수과목 드로어 (DESIGN §2.2). 기존 `Input.jsx` 로직 이식 |
| API 연동 | `POST /roadmap` — **timeout 150초**, AbortController. 상태 5종(INIT/GENERATING/READY/PARTIAL/ERROR) 배선 |
| GENERATING 연출 | 제자리걸음 + 단계 문구 순환 |
| PARTIAL | 미달 구간 붉게 + `details[].fix` 배너 |

**검증 (핵심 — 실서버로)**: ① 데모 시나리오(정보통신공학과 × 시스템관리·운용엔지니어) 생성 → 트랙·배지·`engine: llm` 확인 ② 서버 끄고 → ERROR 상태 확인 ③ `.env` 키 제거 후 생성 → `engine: rule` 폴백 표시 확인.

### P4. 랜딩 2D 전환 (1h)

3D 씬 삭제, DESIGN §5 구성으로 교체. 스크롤 연출은 시간 남으면.
**검증**: 랜딩 → [내 로드맵 그리기] → `/roadmap` 이동. reduced-motion 정상.

### P5. 학과 탐색 + 상세 (1.5h)

카드 그리드(검색·학제 필터) + 상세(커리큘럼 표 + CTA). 전부 번들 데이터 — 서버 불필요.
**검증**: 34개 카드 전부 렌더(수동 스크롤 확인), 상세 → [내 로드맵 그리기] → 학과가 미리 선택된 채 `/roadmap`.

### P6. 스위치 + 통합 (45분)

| 작업 | 내용 |
|---|---|
| 라우트 스위치 | `/` 랜딩 v2, 구 `Input.jsx`·3D 코드 삭제 (이 시점에만) |
| 네비 통일 | 전 페이지 공통 네비 + `/report` 링크 확인 |
| 빌드 서빙 | `npm run build` → `uv run fastapi dev` 로 **서버 정적 서빙 경로에서** 전 화면 클릭 투어 |

**검증**: 데모 대본 전체를 빌드 산출물에서 1회 완주 — 랜딩 → 생성(27초 연출) → 캐릭터 탐색 → 졸업 배지 → 탐색 페이지 → 리포트.
