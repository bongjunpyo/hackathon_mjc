## 협업 구조

파일 소유권을 나눠 병렬로 진행한다. `index.html`은 동제, `style.css`는 효민, `app.js`는 준표가 맡는다.
`app.js`는 세 명이 모두 손대야 하므로 기능 단위로 시간대를 쪼개 한 번에 한 명만 편집한다 —
등록·검증(동제) → 목록 렌더링(준표) → 삭제·확인(효민) 순서다.
각자 자기 담당 범위만 에이전트에 위임하고, 담당 밖 파일은 고치지 않는다.
