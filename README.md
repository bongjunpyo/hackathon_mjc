# MJC 취업 로드맵 에이전트

> 원하는 직무를 고르면, **졸업이 보장되는** 학기별 로드맵(수강·자격증·현장실습)을 짜주는 전문대 특화 AI 에이전트.
> 학교에는 교육과정 ↔ 채용시장 정합도 진단 리포트를 제공한다.

## 문제

전문대는 2~3년 안에 졸업요건·자격증·현장실습·취업을 동시에 끝내야 한다. 한 학기 타이밍을 놓치면 복구할 시간이 없다.
그런데 학생이 손에 쥐는 건 교육과정표 문서 한 장 — "네트워크 엔지니어가 되려면 어느 학기에 뭘 듣고 CCNA를 언제 따야 하는가"는 아무도 알려주지 않는다.

<!-- TODO(제출 전): 페르소나 1명 특정 (액션 8) -->

**지금은 어떻게 버티고 있나.** 학교 시스템(SMART CARE)의 로드맵은 학생이 **직접 입력해 등록하는** 이력 관리 양식이다. 문제는 학생이 그 빈칸에 뭘 넣어야 할지 모른다는 것. 우리는 그 빈칸을 채워주는 엔진이다 — 우리 출력물이 그 시스템의 입력물이 된다.

## 해결

**LLM은 그럴듯한 거짓말을 한다. 그래서 LLM 위에 졸업요건 검증기(순수 규칙 코드)를 얹었다** — 생성된 로드맵을 결정론적으로 검사하고, 미달이면 미달 사유를 피드백해 재생성시킨다(최대 3회). 우리가 짜준 로드맵은 졸업요건을 충족한다.

### 주요 화면

| 화면 | 설명 |
|---|---|
| 입력 | 학과 → 학년/학기 → 이수과목 체크 → 목표 직무 선택 (로그인 시 자동 채움) |
| 로드맵 뷰 | 학기별 수강·자격증·현장실습 타임라인 + "졸업요건 충족 ✓" 배지 |
| 리포트 뷰 | 학교용: 직무별 교육과정 커버리지 / 결손 / 라벨 불일치 진단 |
| 메인·로그인 | 랜딩 + JWT 로그인 (게스트 모드 지원) |

## 실행 방법

```bash
git clone https://github.com/bongjunpyo/hackathon_mjc.git
cd hackathon_mjc
docker compose up -d db                    # PostgreSQL
cd web && npm install && npm run build     # 프론트 빌드
cd ../server && uv sync && uv run fastapi dev main.py   # 서버 (web/dist 정적 서빙 포함)
```

## 기술 스택

| 구분 | 사용 기술 | 선택 이유 |
|---|---|---|
| 프론트 | React + Vite + Tailwind | 화면 5개, 빌드 산출물을 서버가 정적 서빙 — 실행 1커맨드 재현성 |
| 백엔드 | FastAPI (uv, Python) + PostgreSQL | 팀 숙련 스택. DB는 유저 데이터 전용, 과목 데이터는 JSON 시드 |
| LLM | Claude API (`claude-sonnet-5` / `claude-haiku-4-5`) | 이형 포맷 교육과정표 구조화 추출 + 로드맵 에이전트. **검증기는 LLM 없음** |
| 데이터 | 명지전문대 전 학과 교육과정표 → `data/*.json` | 학과별 파서가 아니라 추출 파이프라인 하나로 전 학과 처리 (2계층 품질) |
