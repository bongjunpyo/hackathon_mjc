# server — 주요 기능

원하는 직무를 고르면 졸업이 보장되는 학기별 로드맵을 짜주는 전문대 특화 API 서버입니다. 학교에는 교육과정 진단 리포트를 제공합니다.

## 구성

```text
server/
├── main.py            API 표면 · 생성기 선택 · 라우트 등록
├── catalog.py         data/depts/*.json 유일 창구 + 경계 검증
├── validator.py       졸업요건 검증기 (순수 규칙, LLM 없음)
├── loop.py            생성 → 검증 → 재생성 루프
├── planner.py         결정론적 로드맵 생성기 (직무 역산)
├── agent.py           LLM 로드맵 생성기 (Claude)
├── jobmap.py          진로 ↔ 인재양성유형 매핑
├── report.py          트랙 B 교육과정 진단
├── auth.py            회원가입 · 이메일 인증 · 로그인
├── security.py        bcrypt 해싱 · JWT · 인증 토큰
├── mailer.py          인증 메일 (SMTP 없으면 콘솔)
├── db.py · models.py  PostgreSQL (유저 데이터 전용)
├── errors.py          { error: { code, message } } 통일
├── envfile.py         .env 로더
├── metrics.py         검증기 효과 측정
└── verify_db.py       실DB 검증 스크립트
```

## Tech Stack

| Category | Stack | Description |
|---|---|---|
| Backend | FastAPI (uv, Python 3.11+) | REST API, 비즈니스 로직 |
| Database | PostgreSQL 16 | **유저 데이터 전용** — 과목 데이터는 `data/depts/*.json` |
| ORM | SQLAlchemy 2.0 + psycopg | 마이그레이션 없이 `create_all` (해커톤 범위) |
| Authentication | JWT (PyJWT) + bcrypt | 액세스 12시간 / 리프레시 7일 |
| AI | Claude API (`claude-sonnet-5`) | 로드맵 생성. 키가 없으면 규칙 생성기로 대체 |
| Validation | 순수 규칙 코드 | **검증기는 LLM을 쓰지 않는다** |
| Mail | smtplib | SMTP 미설정 시 콘솔 출력으로 대체 |
| Test | pytest | 135개 |
| Container | Docker Compose | PostgreSQL 로컬 실행 |

## 주요 기능

| 영역 | 기능 |
|---|---|
| 졸업요건 검증 | 전공·교양필수·재학학기 룰(2/3년제), 이수 학점·학기 합산, 남은 학점 산출, 미달 사유 구조화, 형식 오류 과목 검출 |
| 로드맵 생성 | 목표 직무 역산(`talent_type` 라벨), 필수 과목 고정, 직무 관련 과목 우선 배치, 자격증 학기 배치, 학기별 설명 |
| 재생성 루프 | 생성 → 검증 → 미달 사유를 프롬프트로 되먹임, 상한 3회, 초과 시 부분 로드맵을 정상 응답으로 |
| 생성기 이중화 | API 키 유무로 LLM/규칙 자동 선택, LLM 실패 시 규칙 생성기로 폴백, 무엇이 돌았는지 응답에 표시 |
| 직무 매핑 | 학과 소개 페이지의 진로 ↔ 교육과정표의 인재양성유형 연결, 대응 없는 진로는 안내 문구로 공개 |
| 학과 카탈로그 | 34개 학과 로드, 로드 시점 경계 검증(`course_id` 유일성·빈값·`category`·`years`), 없는 `course_id` 보고 |
| 트랙 B 진단 | 직무별 커버리지·결손, 라벨 품질 4종 검출(묶임·비직무·오타·중복 표기), 추출 신뢰도 공개 |
| 인증/회원 | 회원가입, 이메일 인증(30분 만료·재발송), 1회용 교환 코드로 자동 로그인, JWT 발급, 학번 기반 로그인 |
| 내 정보 | 이수 과목 저장·조회, 로드맵 저장(직무별 덮어쓰기) |
| 정직성 장치 | 수치를 지어내지 않음, 없는 과목을 만들지 않음, 무엇이 어긋났는지 응답에 남김 |

## 설계에서 중요한 결정

| 결정 | 이유 |
|---|---|
| **검증기는 LLM을 쓰지 않는다** | 판정이 매번 달라지면 "졸업 보장"이 성립하지 않는다 |
| **총학점은 미달로 잡지 않는다** | 교육과정표가 전공 전용 문서라 교양선택·일반선택이 없다. 판정 근거가 없는 몫은 `remaining_credits`로 알린다 |
| **없는 과목을 지어내지 않는다** | "일반선택 22학점" 블록을 깔면 화면만 채우고 학생은 뭘 들을지 모른다 |
| **직무 역산은 학교 라벨로** | 추천 근거가 데이터 안에 있어 "왜 이 과목이냐"에 답할 수 있다 |
| **JWT를 URL에 싣지 않는다** | 인증 후 60초 1회용 교환 코드로 넘긴다. 방문기록에 남아도 이미 소진돼 쓸모없다 |
| **인증은 코어와 분리** | `include_router` 한 줄만 빼면 게스트 경로가 그대로 돈다 |
| **DB가 없어도 서버는 뜬다** | 코어는 DB를 쓰지 않는다. 연결 실패는 인증 계열만 503으로 떨어뜨린다 |

## 만들지 않은 것

| | 이유 |
|---|---|
| 소셜 로그인 · 권한 등급 | 데모에 보이지 않는다 |
| 수강신청 연동 · 채용공고 크롤링 | 범위 밖 (설계서 §3) |
| DB 마이그레이션 (Alembic) | `create_all`로 충분한 범위 |
| 교양선택·일반선택 과목 배치 | 데이터에 그 과목이 없다. 지어내지 않고 남은 학점만 알린다 |
| NCS 직무기술서 대조 | 수집되지 않았다. 학교가 자기 문서에 써둔 두 값만 비교한다 |

## 빠른 실행

### 1. PostgreSQL 실행

```bash
docker compose up -d db        # 저장소 루트에서
```

> 컨테이너는 **5433**으로 노출합니다. 5432는 로컬 PostgreSQL과 충돌할 수 있고, 그때 "mjc 사용자 인증 실패"가 나는데 연결 거부가 아니라 거절이라 원인이 안 보입니다.

### 2. 환경 변수

`server/.env`에 설정합니다. 전체 항목은 `.env.example` 참고.

```env
DATABASE_URL=postgresql+psycopg://mjc:mjc@localhost:5433/mjc
JWT_SECRET=replace-with-secure-random-string
ANTHROPIC_API_KEY=
```

- `ANTHROPIC_API_KEY`가 **있으면 LLM 생성기**, 없으면 규칙 생성기가 돕니다. 응답의 `generator` 필드로 확인합니다.
- SMTP를 비워두면 **인증 링크를 서버 콘솔에 찍습니다.** 데모 당일 메일이 막혀도 시연이 죽지 않습니다.

### 3. 서버 실행

```bash
cd server && uv run fastapi dev main.py
```

- Swagger: `http://127.0.0.1:8000/docs`
- OpenAPI JSON: `http://127.0.0.1:8000/openapi.json`

### 4. 테스트

```bash
cd server && uv run pytest                      # 135개
PYTHONUTF8=1 uv run pytest                      # 윈도우에서 한글 테스트 이름이 깨질 때
uv run python metrics.py                        # 검증기 효과 지표
uv run python verify_db.py                      # 실DB 전 구간 검증 (13건)
```

## 주요 API 그룹

| Prefix | 설명 | 토큰 |
|---|---|---|
| `/depts` | 학과 목록, 목표 직무·자격증 선택지 | 불필요 |
| `/roadmap` | 로드맵 생성 + 졸업요건 검증 | 불필요 |
| `/report` | 트랙 B 교육과정 진단 리포트 | 불필요 |
| `/auth` | 회원가입, 이메일 인증, 교환, 로그인, 재발송, 리프레시 | 불필요 |
| `/me` | 내 정보, 이수 과목, 저장 로드맵 | **필요** |

**코어 3종(`/depts` `/roadmap` `/report`)은 토큰이 없어도 200을 냅니다.** 게스트 모드가 필수 경로입니다.

상세 명세는 [API 명세](API.md)를 참고합니다.

## 검증 지표

```
시나리오 152개 (34개 학과 × 목표 직무 × 재학 시점 2종) — 결정론적 planner 기준

  검증기 재생성 루프 OFF (1차 생성만)    41 / 152    27.0%
  검증기 재생성 루프 ON  (최대 3회)     150 / 152    98.7%
```

남은 미달 2건은 드론정보공학과로, 개설 전공 과목이 43학점뿐이라(요건 45) 어떤 로드맵으로도 통과할 수 없는 실제 교육과정 공백입니다.

> **"LLM 단독 27%"로 부르면 거짓입니다.** 이 수치는 규칙 생성기 기준입니다 — "1차 생성 27%"가 정확합니다.

## 운영 전 주의사항

현재 코드 기준으로 데모·제출 전에 검토해야 할 항목입니다.

- **프론트 타임아웃이 4초입니다.** LLM 생성은 18~68초 걸립니다. 그대로 두면 서버가 정상 동작해도 목데이터로 떨어집니다. `web/src/lib/api.js`의 `postRoadmap`만 90초로 올려야 합니다.
- **`ANTHROPIC_API_KEY`가 실제로 들어갔는지 확인해야 합니다.** 없으면 규칙 생성기로 돌고, 동작은 하지만 "제품이 AI를 호출한다"는 서술이 성립하지 않습니다. 응답의 `generator` 필드로 즉시 확인됩니다.
- **DB 마이그레이션 도구가 없습니다.** 앱 시작 시 `create_all()`을 씁니다. 스키마를 바꾸면 기존 볼륨을 지워야 합니다 (`docker compose down -v`).
- **동결 스펙과 구현이 11군데 다릅니다.** 설계서 반영은 이슈 #24에서 진행 중입니다. 목록은 [API 명세](API.md) 마지막 절에 있습니다.
- **드론정보공학과는 어떤 로드맵으로도 졸업요건을 통과할 수 없습니다.** 데모에서 이 학과를 고르지 않아야 합니다.
- **테스트는 외부 API를 호출하지 않습니다.** `tests/conftest.py`가 키를 지워 규칙 생성기로 고정합니다. 이 장치를 없애면 테스트마다 유료 호출이 나가고 스위트가 5분 넘게 멈춥니다.
