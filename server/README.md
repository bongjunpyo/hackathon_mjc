## 테스트

```bash
uv run pytest
```

윈도우에서 한글 테스트 이름이 깨져 보이면 `PYTHONUTF8=1 uv run pytest`. 실패한 테스트가 뭔지 못 읽으면 디버깅이 안 된다.

## 검증기

`validator.py` — `validate_roadmap(semesters, years)` → 동결 스펙의 `validation` 객체.
LLM을 쓰지 않는 결정론적 규칙 코드다. 졸업요건 4종(총학점·교양·전공·재학학기)을 2/3년제로 분기해 검사하고,
미달 항목마다 `{rule, label, required, actual, shortfall, fix}`를 낸다. `fix`는 재생성 프롬프트에 그대로 들어간다.

**룰을 바꾸면 `REQUIREMENTS` 상수만 고친다.** 판정 로직은 건드릴 필요가 없다.

## 검증기 효과 지표 (설계서 §9)

```bash
uv run python metrics.py        # 표
uv run python metrics.py --md   # README용 마크다운
```

전 학과 실데이터로 재생성 루프를 끄고/켜고 비교한다. 발표·README에 그대로 싣는 숫자다.

> **재는 대상은 결정론적 planner다.** "LLM 단독 15%"로 부르면 거짓이다 — 심사에서
> "15%는 어느 모델입니까"에 답이 없다. **"1차 생성 15.0%"**가 정확하다.

| 검증기 재생성 루프 | 졸업요건 충족 | 충족률 |
|---|---:|---:|
| OFF (1차 생성만) | 41 / 274 | 15.0% |
| **ON (최대 3회)** | **272 / 274** | **99.3%** |

시나리오 274개 = 전 학과 × 목표 직무 × 재학 시점 2종(1학년 1학기 / 2학년 1학기).
목표 직무는 `GET /depts`가 내보내는 것 전부(`talent_types` + `careers`)다 — `careers`만
돌렸을 때는 데모 대본의 직무(`시스템관리·운용엔지니어`)가 측정에서 빠져 있었다.
남은 미달 2건은 드론정보공학과로, 개설 전공 과목이 43학점뿐이라(요건 45) 어떤
로드맵으로도 통과할 수 없는 실제 교육과정 공백이다.

**OFF일 때 미달 사유는 `major_credits` 233건 · `semesters` 173건이다.** 1차 생성이
목표 직무에 필요한 과목만 짜기 때문이고, 그 간극을 검증기가 잡아 채운다.
재생성 분포는 1회 41건 · 2회 231건 · 3회 2건 — **대부분 한 번의 되먹임으로 붙는다.**
