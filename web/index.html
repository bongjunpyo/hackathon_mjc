이 메인 페이지가 하는 일

레퍼런스(갤러리 워크스루)의 "관람객이 그림 사이를 걷는다"를 "학생이 행선판 사이를 걸어 목적지에 도착한다"로 치환한 컨셉입니다. 명지전문대 브랜드 컬러(네이비 #002D65 · 스카이 #6DCBF9 · 옐로 #FFBA00)를 그대로 썼습니다.

행선판 = 학기

지하철 행선판 문법(이전역 ← 현재 → 다음역)이라 설명 없이 읽힙니다. 각 판 아래 백판에 과목·학점, 노란 배지에 자격증 타이밍.

복도 끝 = 목표 직무

스크롤을 끝까지 가면 금색 게이트(행선지)와 "졸업요건 충족 ✓" 검증 배지 — 발표 훅("저희 로드맵은 100% 졸업 가능합니다")이 화면으로 증명됩니다.

기술

CSS perspective + sticky + 스크롤 진행률 변수 하나. 외부 라이브러리 0. prefers-reduced-motion이면 세로 목록으로 풀립니다.
